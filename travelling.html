(2026年からの) 旅行・お散歩の記録です。アイコンは飛行機ですが、夜行バス (一睡もできない!) と電車による移動がほとんどです。

岐阜 (2026.09.26-29)

1日目 : 神田 (19:30発) → 富山 (26:00着) [約430km,5時間30分]
  • まるたかや 駅前店 (ラーメン, 27時まで営業)
黒部ダムは車のみではアクセスできない (関電トンネルはバスでしか通れない) ので, 断念.
2日目 : 富山(6:30発) → 白川郷 (8:00着) [約85km, 1時間30分], 白川郷(12:00発) → 高山(13:00着) [約50km, 1時間]
  • 白川郷観光 (駐車場8:00~)
  • まさごそば (ラーメン, 15:30まで営業)
  • 三町伝統的建造物群保存地区 (古い町並み, 例えばこのようなカフェがあるらしい)
  • 飛騨の味 酒菜 (18:00~)
  • ユトリアリゾート飛騨高山 (12,292円) [〒506-0851 岐阜県, 高山市, 大新町 5-141-2]
3日目 : 高山(6:30発) → ナガスパ(9:30着) [約180km, 2時間30分], ナガスパ → 中津川 [約100km, 1時間30分]
  • ナガスパ (9:30~16:30)
  • 中津川は何もないので, ナガスパエリアで夜ご飯を食べる戦略が賢いか?
  • Haraya [〒508-0042 岐阜県, 中津川市, 中津川市西宮町4－31] (17,000円)
4日目 : 中津川(8:30発) → 馬籠宿(9:00着) [約15km, 30分], 馬籠宿(13:00発) → 神田(19:00着) [約300km, 4時間]
  • 川上屋 (栗きんとん), 四方木屋 (わらびもち) など, 甘味
とりあえず, 宿泊費+移動費(ガソリン代, 高速代抜き)で1人当たり19,300円くらい.

岩手 (2026.09.17-18)

1日目 : 東京駅(7:32発) → 盛岡駅(9:44着)
  1. 東家 (わんこそば, 当日10時30分から予約可能, 4,500円)
  2. 盛岡八幡宮
  3. 鮨懐石 重兵衛 (18:30~)
  4. アートホテル盛岡
候補として,
  • 盛岡八幡宮を除いて小岩井農場 (バスで35分, 750円)
2日目 : 盛岡駅(8:56発) → 平泉駅(10:20着) → 一ノ関駅 → 東京駅
  1. 毛越寺
  2. 中尊寺
候補として,
  • 午前中に宮沢賢治記念館, その場合 盛岡駅 → 新花巻駅 (やまびこで10分1,600円, 在来線だと1時間800円), 新花巻駅から徒歩40分程度
  • さかえや本店で満州にらラーメンを食べる, ただし花巻駅から4kmくらいある
ただし移動が多く, 大変かも.

三重 (2026.04.05-07)

正確には徳島から大鳴門橋と明石海峡大橋を渡って本州に上陸し、三重で1泊してから東京に戻る、という車旅であった。父、兄との3人での旅行で、若輩者としてもちろん運転を買って出たのだが、あいにく運転免許を持ち合わせていなかった!ので、語り部を担当した (そんな役目があるのか?)。四日市で一晩過ごしたのち、伊勢神宮を参拝したが、時間の都合で本居宣長の旧宅・鈴屋には行けなかった。

新潟・長野 (2026.03.17-19)

上越新幹線で新潟駅へ、そこからJR&えちごトキめき鉄道を乗り継いで、糸魚川に向かって新潟を横断した。そこから長野へ向かい、北陸新幹線で東京に戻るという円を描くような鉄道旅は、素晴らしい思い出となった。 (無茶な計画に付き合ってくれた友人2人のおかげである。感謝するとともに、真っ当な感性の持ち主であれば謝罪するに違いない、と想像してみる。) それにしても酒蔵数ランキング1位・2位を占める新潟と長野だけあって、どこに行っても地酒が付きまとう。「日本酒は体に馴染む。これこそ調和だ!」と豪語する私が自制できるはずもなく、三日三晩飲み続けることとなった。

徳島 (2026.03.12-14)

父の故郷であり、そのおかげでほぼ私の故郷となった徳島へ。19歳!の空海が虚空蔵求聞持法を修め、空海の"空"を名乗るきっかけとなった太龍寺の舎心ヶ嶽に連れて行ってもらった。もはやその空海より年上の私といえば、ボウゼが酢〆でしか提供されないことばかり気にかけて、「本当に美味しいボウゼの刺身は徳島人が独占しているのではないか」と想像を膨らませるのであった。

群馬 (2026.02.14)

在来線で3時間かけて高崎へ。赤城山を眺めながら縁起だるま発祥の地たる少林山達磨寺に向かい、お寺を散策した。達磨寺では般若心経を1行写経した証に御朱印をもらえる。私の父は御朱印集めをスタンプラリーと思っている節があるので、ぜひとも一度達磨寺を訪ね、自分を見つめ直してほしいものだ。 ちなみに1行写経の前に願意を四字熟語で書き入れるのだが、あとで住職に「Riku the hat 願うところの心願成就」うんたらと読み上げられる。ボケで「腹十分目」と書くことを踏みとどまった私は、胸をなでおろした次第である。

宮城 (2026.02.07-08)

今年初の仙台へ、友人2人と夜行バスで向かった。志波彦神社・鹽竈神社を参拝し、フェリー (芭蕉コース) で松島を訪れ、何気に初めて瑞巌寺に参詣した。塩竈は衆院選2026で話題沸騰の宮城4区に含まれることを知った。
